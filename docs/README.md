# Documentation

## Overview

This directory contains documentation for the AI-Powered Algorand Smart Contract Creator.

## Structure

### Internal Review Notes

The `internal/` folder contains detailed implementation and assessment reports intended for development review and governance evaluation:

- **REPORT_1_HOW_IT_WORKS.md** – Architecture, runtime flow, key modules, and current code quality posture.
- **REPORT_2_XGOV_FIT_ASSESSMENT.md** – Assessment of project fit for Algorand xGov as an ecosystem tooling project.
- **DIRECTORY_STRUCTURE_REPORT.md** – Detailed file and folder layout analysis.
- **MCP_TOOLS_RECOMMENDATION.md** – Analysis of Model Context Protocol (MCP) tooling recommendations.
- **TOOLS_TO_DISABLE.md** – MCP tools that can be disabled to reduce complexity.

These documents are **not** end-user documentation and are intended for:
- Project maintainers and contributors
- xGov proposal reviewers and governance stakeholders
- Technical architects evaluating integration or fork opportunities

## User Documentation

User-facing documentation should be placed in the root `README.md` and kept focused on:
- Getting started guide
- Feature overview
- Configuration instructions
- Usage examples
- Troubleshooting

For governance-specific positioning and roadmap, see `xgov-positioning.md` in the root docs folder.
